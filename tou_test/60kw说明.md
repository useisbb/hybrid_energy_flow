# 60kW 混逆 TOU 方案描述与测试记录

## 功能需求：TOU

### 功能描述

根据不同地区的分时电价政策，用户通过 Web、显示屏或云平台配置时段功率计划表（充电 / 放电 / 待机时段及目标功率）。在运行过程中，结合电网侧"防逆流"或"防过载"等保护约束，动态限制逆变器的逆变侧功率，使并网口实际有功功率跟随计划值。混合逆变器根据逆变目标功率自动控制内部能量流（光伏、电池），实现峰谷套利，同时确保系统安全运行。

## 输入

- 电池相关信息
  - SOC（多簇平均）
  - 最大可充功率（参数限制）
  - 最大可放功率（参数限制）
- 逆变器的实时逆变功率（实时数据）
- 电网侧表 PCC 有功功率（实时数据）
- 时段配置、功率配置、SOC 范围
- 逆流保护配置、过载保护配置
- 电网取电功率最大值（变压器容量）
- 电网取电功率最小值（防逆流余量）

## 输出

- 逆变限制功率
- 电池口功率（静置用）

## 业务规则

### 1. 时段配置

在 Web、显示屏或者云平台配置充放电计划。

### 2. 功率设置

1. 判断当前时刻是否有充放电计划。
2. 分配功率判断。

#### 变量定义

| 符号 | 含义 |
|---|---|
| `P_plan` | 计划值 |
| `P_hybrid` | 逆变侧逆变功率 |
| `P_grid` | 电网侧功率 |
| `P_limit` | 电网容量限制 |
| `P_margin` | 逆流保护余量 |
| `P_∞` | 无效值（寄存器 value=0x7fff） |
| `P_0` | 0 功率 |
| `P_maxcharge` | 混逆系统最大充电功率（配置值 / 实际值） |
| `P_maxdischarge` | 混逆系统最大放电功率（配置值 / 实际值） |

#### 保护限制计算

**保证不过载的最大充电功率：**

- 开启（防过载）：
  `P_maxcharge_limit = P_hybrid + P_grid - P_limit`
  （`P_maxcharge_limit ≤ 0`，大于 0 赋值为 0）
- 关闭：
  `P_maxcharge_limit` 可认为是负无穷大，即该参数不限制充电

**保证不逆流的最大放电功率：**

- 开启（防逆流）：
  `P_maxdischarge_limit = P_hybrid + P_grid - P_margin`
  （`P_maxdischarge_limit ≥ 0`，小于 0 赋值为 0）
- 关闭：
  `P_maxdischarge_limit` 可认为是正无穷大，即该参数不限制放电

#### 逆变设置功率

`P_set = min(P_maxdischarge, P_plan)`

### 3. 时段策略

#### 充电（充电时段，需考虑过载保护）

- 逆流保护开启：
  - 设置功率：`P_set = min(P_maxcharge, P_plan)`
  - 控制逆变口功率 = `P_set`
  - 充满前后：逆变口限制功率 = `P_set`，电池口 = `P_∞`
- 逆流保护关闭：
  - 控制逆变口功率 = `P_set`，电池口 = `P_∞`
  - 充满前：电池从光伏和电网取电，光照不足时剩余部分由电网补电
  - 充满后：光伏电能上网，电池控制 0 功率，电池口功率 = `P_0`，逆变口 = `P_∞`

#### 放电（放电时段，需考虑逆流保护）

- 设置功率：`P_set = min(P_maxdischarge_limit, P_plan)`
- 逆流保护开启 / 关闭：
  - 控制逆变口功率 = `P_set`，电池口 = `P_∞`

#### 待机（待机时段，需考虑逆流保护）

- 逆流保护开启：
  - 控制逆变口功率 = `P_0`，电池口 = `P_∞`
- 逆流保护关闭：
  - 逆变口功率全部逆流到母线上
  - 控制逆变口功率 = `P_∞`，电池口 = `P_0`

## 验收标准

- **计划跟踪**：在无保护约束且电池能力充足时，混逆系统能正常按照配置执行。
- **防过载测试**：开启过载保护，能够根据负载变化从而限制充电，保护电网侧不因混逆充电过载。
- **防逆流测试**：开启防逆流，能够根据负载变化从而限制放电，保护电网侧不因混逆放电逆流。
